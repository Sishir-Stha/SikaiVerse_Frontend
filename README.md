# SikaiVerse Project (Frontend)

This is the frontend for the SikaiVerse Project. It's a React application built with Vite, TypeScript, shadcn-ui, and Tailwind CSS.

## Getting Started

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/Sishir-Stha/FareUpdaterReact.git
    ```s
2.  **Install dependencies:**
    ```sh
    npm install
    ```
3.  **Run the development server:**
    ```sh
    npm run dev
    ```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
